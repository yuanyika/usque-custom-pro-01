# Android 手机

1. 打开自己的 Pages 或 Preview 页面。
2. 手机自己注册或导入私有 Usque config.json；不要上传到仓库或复制电脑的设备凭据。
3. 启用免费落地，选择“📱 手机推荐”，保留美国、AUTO 和 Codex 优化。
4. 点击应用设置、选择 Clash/Mihomo，下载 `mihomo-mobile.yaml`。
5. 在支持 MASQUE 的 Mihomo Android 客户端导入。各客户端 MASQUE 支持程度可能不同，先保留原配置作为回退。

免费 provider 从 Pages 自动更新，每小时更新、15 分钟检查。稳定池最多 8 个，高速 12 个，备用 20 个；电脑关机也能独立更新和连接。AI-US 默认 CODEX-US，US-FAST/US-MANUAL 可手动选择。

YAML 内的 WARP 私钥仍是私有本地文件；不要把整份 YAML 做成公开订阅。仅公共 provider URL 可用于共享。若 Pages 配置 Token，在手机输入它，Token 不保存到云端。

本次只验证合成手机 YAML 的解析和 Mihomo -t，没有操作实体手机、连接真实免费节点或测量手机出口。请在手机实际运营商线路上测试；不要以 PC 延迟推断手机质量。
